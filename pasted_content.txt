## Analysis & Proposed Enhancement Plan

### Issue 1 — Print: Only "العمليات الإدارية" Shows on First Page, Other Tables Don't Follow

**Root Cause:** The `@media print` CSS currently uses `break-inside: avoid` on `.section-block` but does **not** force a proper page-flow for the large tables (journey table, case assignment table, summary table, stats section). The first section fills the first page and the rest are either cut off or pushed to orphaned pages without headers.

**Proposed Fix:**
- Add `page-break-after: auto` and proper `break-before: auto` rules so all sections flow naturally across pages.
- Ensure the report header repeats or is pinned only to the first page using `break-before: page` on the second section onward — but only when content overflows.
- Remove any `min-height: 297mm` constraint from `.report-page` during print so content flows freely across multiple A4 pages.
- Add `break-inside: avoid` specifically to table headers (`thead`) so column headers don't get orphaned.

---

### Issue 2 — Green Underlines in Balance Tables Are Misaligned / Overlapping

**Root Cause:** The `.searchable-field` and `input[type="number"]` elements inside the `.case-tbl`, `.journey-tbl`, and `.sub-tbl` tables use `display: block` with `border-bottom` underlines. When cells have `vertical-align: top` or inconsistent `padding`, the underlines stack or overlap adjacent rows.

**Proposed Fix:**
- Standardize all underline-style inputs to `display: block; width: 100%; box-sizing: border-box` with consistent `padding: 3px 4px; min-height: 24px; line-height: 1.4`.
- Set `vertical-align: middle` uniformly on all `td` elements in these tables.
- Fix the `nat-tag` elements (nationality tags) — currently they use `padding: 6px 12px` which inflates row height unevenly; reduce to `padding: 2px 6px` for compact fit.
- Ensure `table-layout: fixed` is applied consistently so column widths don't collapse.
- Add `overflow: hidden` on cells with long content to prevent bleed.
